# Smart Syllabus Generator Web — UI v1.3.4

เว็บแอป HTML/CSS/JavaScript ประมวลผลใน Browser ไม่ต้องใช้ Backend หรือ Node.js ในการเผยแพร่ด้วย GitHub Pages

## การปรับปรุงจาก v1.3.3

### 1. ปีการศึกษา / ภาคเรียน

- จากภาพที่ผู้ใช้ส่งมา **ช่องปีการศึกษาอยู่ทางขวาและว่างอยู่** ส่วนตัวเลข `1` อยู่ในช่อง **ภาคเรียน** ด้านล่างซ้าย ไม่ใช่ปีการศึกษา
- v1.3.4 แก้สาเหตุที่ค่าจาก **Draft ล่าสุดถูกเปิดอัตโนมัติ** ทำให้ผู้ใช้เข้าใจผิดว่าเป็นค่าเริ่มต้น
- เมื่อเปิดเว็บหรือ Refresh หน้าเว็บ จะเริ่ม **แบบฟอร์มใหม่ว่างเสมอ**: ปีการศึกษาและภาคเรียนไม่มีค่าล่วงหน้า และไม่เรียกข้อมูลวิชาเดิมขึ้นมา
- อธิบายชัดว่าปีการศึกษาและภาคเรียนเป็นคนละช่อง; ค่า 1 ของภาคเรียนอาจเป็นค่าที่ถูกต้องเมื่อผู้ใช้เลือกกรอกเอง

### 2. ผู้รับผิดชอบรายวิชาและผู้สอน

- เมื่อเปิดเว็บหรือสร้าง Draft ใหม่ แท็บผู้สอนแสดง **ยังไม่มีผู้สอน** และปุ่ม **＋ เพิ่มผู้สอน**; ไม่มีแถวกรอกหรือรายชื่อค้างมาจาก Draft ก่อนหน้า
- ไม่สร้างแถวว่างอัตโนมัติ; ผู้สอนจาก Draft เก่าจะปรากฏก็ต่อเมื่อผู้ใช้กด **Draft ของฉัน → เปิด** ด้วยตนเอง
- **ไม่ลบข้อมูล Draft ที่มีอยู่ใน Browser** และยังคง Import JSON ได้เหมือนเดิม

## การเปลี่ยนพฤติกรรมการเรียกคืน Draft (สำคัญ)

เพื่อหลีกเลี่ยงค่าค้างโดยไม่ตั้งใจ **หลัง Refresh จะไม่เปิด Draft ล่าสุดเอง** แม้ระบบ Auto Save ทำงานอยู่:

1. กรอกข้อมูลตามปกติ → ระบบ Auto Save ลง Browser เมื่อมีการแก้ไข หรือกด **บันทึก Draft**
2. เปิดเว็บไซต์หรือ Refresh อีกครั้ง → เริ่มหน้าใหม่ว่าง
3. ต้องการทำงานต่อ → กด **Draft ของฉัน** → เลือก Draft เดิม → **เปิด**
4. ต้องการย้ายเครื่อง/ย้ายจาก localhost ไป GitHub Pages → **เครื่องมือ → สำรอง Draft JSON** แล้ว **นำเข้า JSON** ที่ปลายทาง

**ไม่มีการล้าง IndexedDB/localStorage ของผู้ใช้และไม่ลบ Draft เก่าโดยอัตโนมัติ** อย่าลบข้อมูลเว็บไซต์หรือโปรไฟล์ Browser ก่อนสำรอง Draft สำคัญเป็น JSON

> ถ้าตั้งใจเปิด Draft ที่กรอกภาคเรียน 1 ไว้ ระบบจะยังแสดง 1 ตามข้อมูลที่บันทึก เป็นพฤติกรรมที่ถูกต้อง ไม่ใช่ค่าเริ่มต้นใหม่

## ทดลองบน Windows

```powershell
py -3 -m http.server 8000
```

เปิด `http://localhost:8000/` โดยรันคำสั่งจาก Root ของโฟลเดอร์ที่มี `index.html`

ทดสอบว่า (1) หน้าใหม่ปี/ภาคเรียนว่าง (2) แท็บผู้สอนไม่มีแถว (3) กรอกข้อมูลและบันทึก Draft (4) Refresh แล้วหน้าใหม่ว่าง (5) กด Draft ของฉันและเปิด Draft เดิม ข้อมูลต้องกลับมาครบ (6) ทดสอบ Validate และ Export JSON

## สำหรับนักพัฒนา

- `index.html` — ไฟล์ที่ Deploy ขึ้น Root ของ GitHub Pages
- `src/app.js` — JavaScript source
- `src/styles.css` — CSS เดิม ไม่แก้ในรุ่นนี้
- `tools/build.py` — สร้าง index.html โดยไม่ต้องติดตั้งแพ็กเกจเพิ่ม
- `tools/test_v134.py` — ทดสอบพฤติกรรมการเริ่มต้นแบบว่าง, เปิด Draft เดิม, และ JSON Schema (ต้องมี Playwright, jsonschema และ Chromium เพื่อรันทดสอบ)
- `data/` และ `schema/` — ไม่มีการเปลี่ยน Master JSON และ Schema

สร้างไฟล์หน้าเว็บใหม่เมื่อแก้ `src/app.js`:

```powershell
py -3 tools/build.py
```
