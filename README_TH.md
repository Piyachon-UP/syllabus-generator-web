# Smart Syllabus Generator Web v2.1.0

Web App สำหรับอาจารย์ คณะวิทยาศาสตร์ มหาวิทยาลัยพะเยา ใช้งานผ่าน Browser บน GitHub Pages แบบไม่มี Backend

## ฟังก์ชันเดิมที่ยังคงอยู่

- แบบฟอร์ม 6 หมวด: ข้อมูลรายวิชา, PLOs, ผู้สอน, CLOs, แผนการสอน, การประเมิน
- เปิด JSON รุ่นเดิมมาแก้ไข และบันทึก JSON ได้ตลอดเวลาโดยไม่ต้องผ่าน Validation
- สร้าง DOCX ผ่าน Browser ได้โดยตรง และรองรับ Responsive Desktop/Tablet/Smartphone
- ไม่มีระบบ Auto Save; ต้องดาวน์โหลด JSON ก่อนปิดหน้าเว็บ

## ใหม่: ปฏิทินเลือกวันที่

ในหมวด **ข้อมูลรายวิชา** ตอน `01 · ข้อมูลรายวิชาและภาคเรียน` จะมีช่อง **วันที่บันทึก/ปรับปรุงข้อมูล**

1. คลิกช่องวันที่หรือไอคอนปฏิทิน
2. เลือก **วัน / เดือน / ปี** ตามวันที่ที่ต้องการระบุ (ผู้สอนเป็นผู้กำหนดเอง)
3. ใต้ช่องกรอกจะแสดงวันที่ในรูปแบบ **พ.ศ.** ให้ตรวจสอบ
4. กด **บันทึก JSON** เพื่อบันทึกข้อมูล เช่น `"LastUpdatedDate": "2026-10-29"` ใน `CourseInfo`
5. กด **สร้าง DOCX** เพื่อให้เอกสารแสดง `29/10/2569`

### เงื่อนไข

- ช่องวันที่เป็น **ตัวเลือก ไม่บังคับกรอก** เพื่อให้ไฟล์ JSON เก่าเปิดได้
- วันที่จะไม่ถูกแก้อัตโนมัติเมื่อโหลด JSON หรือกดบันทึก: ผู้สอนต้องเลือก/เปลี่ยนเอง
- ไฟล์เก่าที่ไม่มีวันที่จะเริ่มต้นช่องนี้เป็นค่าว่าง
- ใน JSON ใช้มาตรฐานปี ค.ศ. แบบ `YYYY-MM-DD` และแสดง พ.ศ. เฉพาะที่อ่านในเว็บ/Word
- Browser แต่ละเครื่องอาจแสดงตัวเลขวันที่ในช่องต่างรูปแบบกัน เช่น `10/29/2026` แต่ข้อมูลเก็บเป็น ISO เดียวกัน

## ข้อมูลสำหรับพัฒนาและ Blazor

ไฟล์ `schema/syllabus.v1.schema.json` ขยายฟิลด์ `CourseInfo.LastUpdatedDate` แบบไม่บังคับ โดย **SchemaVersion ยังเป็น 1.0.0** เพื่อรักษาแนวทาง JSON-only เดิม

ควรอัปเดต Schema/DTO ฝั่ง Blazor ก่อนนำ JSON ที่มีฟิลด์ใหม่ไป Import เพราะ schema รุ่นเก่าที่ปฏิเสธ `additionalProperties` จะไม่รับฟิลด์ใหม่นี้ (อ่านรายละเอียดเพิ่มเติมใน `CHANGELOG_TH.md`)

## ทดสอบ

```powershell
py -3 -m http.server 8000
```

เปิด `http://localhost:8000/` แล้วทดลองใน Browser หรือรัน Regression Test บนเครื่องพัฒนา:

```powershell
py -3 tools/test_calendar_v21.py
```
